# nodejs-hw

Простий сервер на Express для роботи з нотатками. Є маршрути для перегляду всіх нотаток, однієї нотатки за індентифікатором та ручка для тесту помилок.

## Як запустити

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть сервер у звичайному режимі:
   ```bash
   npm run start
   ```
3. Для режиму розробки з перезапуском використовуйте:
   ```bash
   npm run dev
   ```

Сервер використовує порт з `.env` (змінна `PORT`) або 3000 за замовчуванням.
